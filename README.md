# Сложно сосредоточиться

Адаптивная статья с галереей и тремя режимами оформления: «день», «неон» и «авто». Выбранный режим сохраняется в браузере, а режим «авто» следует системной цветовой схеме.

Для локального просмотра откройте `index.html` на статическом сервере:

```sh
python -m http.server 8000
```

Затем откройте http://localhost:8000. Для проверки измените ширину окна, переключите темы, обновите страницу и пройдите по ссылкам и кнопкам клавишей Tab.
